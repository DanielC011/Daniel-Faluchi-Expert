Landing Page profissional **Mobile First** de alta conversão para venda de serviços de criação de Landing Pages.

## 🚀 Como Personalizar Facilmente

Todas as informações de textos, links, cores, projetos demonstrativos e perguntas frequentes estão centralizadas em um único arquivo:

👉 **`src/config.ts`**

Neste arquivo você pode alterar:
- Seu nome e marca (`name`)
- Link do WhatsApp (`whatsappUrl`: `https://w.app/shpfsu`)
- Textos dos botões e chamadas para ação
- Demonstrações conceituais de projetos
- Perguntas e respostas do FAQ

---

## 📦 Como Publicar na Vercel (2 Opções)

### Opção 1: Direto com o repositório GitHub (Recomendado)
1. Suba este projeto para o seu GitHub.
2. Na Vercel, clique em **Add New... > Project** e selecione o repositório.
3. A Vercel detecta automaticamente o **Vite** e faz o build com 1 clique (comando: `npm run build`, pasta: `dist`).

### Opção 2: Versão Pura em HTML + CSS + JS Puro
Se preferir subir arquivos sem nenhum framework nem etapa de build (HTML, CSS e JavaScript puros), acesse a pasta:
👉 **`pure-html-version/`**
- `index.html`
- `style.css`
- `script.js`

Basta arrastar para a Vercel, Netlify ou qualquer hospedagem tradicional (cPanel, Apache, Nginx, GitHub Pages).

1. **Hero — Primeira Dobra**: Headline de alto impacto, CTA principal e mockups visuais em celular e computador.
2. **O que é uma Landing Page**: Explicação didática com o fluxo visual `Visitante → Landing Page → Contato → Cliente`.
3. **Por que meu negócio precisa**: Situações comuns do dia a dia e 6 cartões de benefícios concretos.
4. **Não é apenas uma página bonita**: 8 pilares estratégicos de arquitetura de conversão.
5. **O que eu faço por você**: Processo em 4 etapas (Entendimento, Estrutura, Design e Entrega).
6. **O que você recebe**: Checklist de 13 entregáveis inclusos.
7. **Demonstrações**: Exemplos conceituais para prestadores de serviço, negócios locais, autônomos, infoprodutos e empresas B2B.
8. **Por que fazer comigo**: 6 diferenciais reais de atendimento e qualidade técnica.
9. **Como funciona**: 3 passos claros até a entrega.
10. **CTA Intermediário**: Chamada de alto contraste focada em orçamentos.
11. **FAQ Interativo**: Respostas para as principais dúvidas em acordeão suave.
12. **CTA Final**: Fechamento persuasivo direcionando para o WhatsApp.
13. **Rodapé e Barra Flutuante**: Acesso instantâneo ao WhatsApp no mobile e desktop.
